# Wayland-Godot — Kiosk Compositor for CyberRealm

A minimal Wayland compositor (C, **wlroots 0.18**) whose only job is to launch the
exported build of **CyberRealm** (`CyberRealm/build/CyberRealm.x86_64`) fullscreen,
in kiosk mode. Exiting the game stops the compositor.

Two implementations live in this repository:

| Component | Path | Status |
|---|---|---|
| **Kiosk compositor** | `minimal/` | **Working solution** — standalone C + wlroots 0.18 |
| GDExtension prototype | `src/`, `protocols/`, `SConstruct` | Superseded prototype (renders Wayland windows as 3D quads in Godot) |

---

## Kiosk Compositor (`minimal/`)

### Build

```bash
# Dependencies (Arch Linux)
sudo pacman -S wlroots0.18 wayland wayland-protocols pixman libdrm xkbcommon

cd minimal
make          # produces ./cyberrealm
```

`wayland-scanner` generates the protocol headers (`xdg-shell-protocol.h`,
`pointer-constraints-unstable-v1-protocol.h`) into `minimal/` at build time.

### Run on a real TTY (DRM)

```bash
sudo systemctl start getty@tty3.service   # free a VT
# Ctrl+Alt+F3, log in, then:
cd /home/adrien/Projets/wayland-godot/minimal && ./cyberrealm
```

- The compositor takes over the VT and launches the game fullscreen on the real
  display (Intel Iris Xe, DRM backend). The game runs as the only client.
- Exit the game, or press **Ctrl+Alt+Q**, to stop the compositor and return to the console.
- Back on tty2: `sudo systemctl stop getty@tty3.service` when done.

### Headless / nested test (no physical display)

```bash
env -u WAYLAND_DISPLAY WLR_BACKEND=headless WLR_RENDERER=pixman \
  ./cyberrealm -c "wayland-info"
# or nested under an existing desktop session:
env -u WAYLAND_DISPLAY ./cyberrealm -c "weston-terminal"
```

### Options

```
Usage: ./cyberrealm [-c command] [-h]
  -c command   Launch command instead of the CyberRealm build
  -h           Show this help
```

Without `-c`, the compositor derives the game path from `/proc/self/exe`
(`../CyberRealm/build/CyberRealm.x86_64`). `XDG_RUNTIME_DIR` must be set.

### Features

- **Single-toplevel kiosk**: the first mapped window is forced fullscreen and
  focused; closing/unmapping it terminates the compositor.
- **Auto-launch**: the game is forked after the Wayland socket is created
  (`/bin/sh -c <command>` or the derived game path).
- **Early pointer enter**: the seat sends `wl_pointer.enter` directly on the
  toplevel surface as soon as it is created — before the window maps — because
  Godot requests `MOUSE_MODE_CAPTURED` in `_ready()` and would otherwise fail
  (`ERR_FAIL_NULL(pointed_win)`), silently ignoring all mouse motion.
- **Relative pointer motion** (`zwp_relative_pointer_v1`) and **pointer
  constraints** (`zwp_pointer_constraints_v1`) so FPS controls work.
- **Keyboard**: xkbcommon keymap (layout `fr` by default, override with
  `XKB_DEFAULT_LAYOUT`), Ctrl+Alt+Q to quit.
- **Clean shutdown**: `SIGCHLD` is handled via `wl_event_loop_add_signal`; the
  game gets `SIGTERM` on exit and the display run terminates cleanly.
- **Globals**: `wl_compositor` v5, subcompositor, data device manager,
  `linux_dmabuf_v1` v4, presentation, pointer constraints, relative pointer.

### Known notes

- The game launches its own headless Wayland compositor (the waylandgodot
  extension) on `wayland-1`; that is normal and separate from this kiosk.
- Headers generated by `wayland-scanner` in `minimal/` must not be deleted.

## GDExtension Prototype (superseded)

A full-featured Wayland compositor implemented as a Godot 4 GDExtension,
rendering Wayland windows as textured 3D quads inside a Godot scene. Headless
via `wlr_headless_backend`; the scene is `CyberRealm/source/scenes/wayland_room.tscn`.

```bash
scons target=template_debug platform=linux    # builds libwaylandgodot into CyberRealm/source/bin/
```

Open `CyberRealm/source/` in Godot 4 and run `wayland_room.gd`. The exported
build in `CyberRealm/build/` bundles this extension.

### Compositor core (C++, wlroots 0.18)

- Headless backend + fake 1280x720 output at up to 120 FPS
- Protocols: `wl_compositor` v6, `wl_seat`, `xdg_shell` v3, `wl_subcompositor`,
  `wl_viewporter`, `linux_dmabuf_v1` v4, `wl_data_device_manager`,
  `wl_primary_selection_v1`, `zwp_pointer_constraints_v1`, `zwp_relative_pointer_v1`

### Three-tier rendering pipeline

Auto-negotiated per-surface, in priority order:

1. **Vulkan zero-copy (GPU → GPU)** — wlroots renders to a DMA-BUF, imported
   into Godot's Vulkan device via `VK_KHR_external_memory_fd`; no mmap/memcpy.
   Cross-API sync via `DMA_BUF_IOCTL_EXPORT_SYNC_FILE`. Force with nothing — it
   is the default; fallbacks below.
2. **DMA-BUF + mmap** — linear-modifier buffers read on the CPU, BGRA→RGBA
   swizzle, `CaptureCache` reuses buffers.
3. **Pixman CPU** — software rendering via `wlr_buffer_begin_data_ptr_access`;
   force with `WAYLANDGODOT_FORCE_PIXMAN=1`.

### Window management & input

- Toplevels spawn as 3D quads; nested popups, drag-and-drop with drag icon,
  middle-click drag / titlebar drag, 8-zone resizing, scroll-depth adjust
- Virtual software keyboard (XKB layout `fr`, 75+ key map, AltGr, AZERTY fixes)
- Pointer: absolute motion + raycast hit-testing, `zwp_relative_pointer_v1`,
  pointer lock via `zwp_pointer_constraints_v1`
- **Focus mode (F)** — fullscreen `TextureRect`, auto pointer-lock for FPS games
- **Pin (P)** — stacked PiP thumbnails
- **Launcher (R)** — parses `.desktop` files, categories, search, F1–F12 favorites
- **Window menu (B)** — tabs, live preview, GRAB/FOCUS/HIDE/PIN/FIND/QUIT
- **Pause/settings menu (Escape)** — resolution presets, keybinds, FPS toggle,
  persisted to `user://settings.json`
- XWayland via `xwayland-satellite :1`; child processes tracked and SIGTERMed
- Desktop notifications via `dbus-monitor`

### GDExtension signals

| Signal | Parameters | Description |
|---|---|---|
| `window_mapped` | id, title, app_id | New toplevel window |
| `window_unmapped` | id | Toplevel window closed |
| `window_texture_updated` | id, texture, width, height | Content re-rendered |
| `popup_mapped` | id, parent_window_id, parent_popup_id, x, y, w, h | Popup appeared |
| `popup_unmapped` | id | Popup closed |
| `popup_texture_updated` | id, texture, width, height | Popup re-rendered |
| `pointer_lock_changed` | window_id, locked | Pointer lock toggled |
| `window_fullscreen_changed` | id, fullscreen | Fullscreen state changed |
| `drag_icon_updated` | texture, width, height | Drag icon appeared |
| `drag_icon_removed` | — | Drag icon removed |
| `notification_received` | app_name, summary, body, app_icon, urgency | Desktop notification |
